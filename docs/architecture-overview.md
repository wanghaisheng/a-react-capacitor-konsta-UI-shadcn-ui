# 架构总览文档

## 技术栈

### 前端框架
- React 18.3.1
- TypeScript 5.7.3
- Vite 5.4.14 (构建工具)

### UI组件库
- Konsta UI 4.0.1
- shadcn/ui
- Tailwind CSS 3.4.17

### 移动框架
- Capacitor 7.0.1
- iOS 14.0+
- Android API 23+

### 包管理
- pnpm 8+

## 核心模块

### 1. 应用入口层
- `App.tsx`: 应用主组件
  - 路由配置
  - 主题管理
  - 全局状态
  - 错误边界

### 2. 视图层
- `views/`: 页面组件
  - 首页
  - 愿望设置
  - 进度追踪
  - 排行榜
  - 个人资料

### 3. 工具层
- `lib/utils.ts`: 通用工具函数
- 国际化支持
- 主题切换
- 数据持久化

### 4. 移动平台层
- Android
  - Java/Kotlin原生代码
  - WebView集成
  - 原生功能调用

- iOS
  - Swift原生代码
  - WKWebView集成
  - 原生功能调用

### 5. 配置层
- 构建配置
- 样式配置
- 类型定义
- 环境变量

## 数据流

1. 用户交互 -> 视图组件
2. 视图组件 -> 状态管理
3. 状态管理 -> 数据持久化
4. 数据持久化 -> 本地存储/云端同步

## 主要技术特点

1. 跨平台开发
   - 使用Capacitor实现iOS/Android原生功能
   - 统一的Web代码库

2. 现代化UI
   - 响应式设计
   - 暗色模式支持
   - 组件化开发

3. 性能优化
   - Vite快速构建
   - 按需加载
   - 代码分割

4. 开发体验
   - TypeScript类型安全
   - 热更新
   - 开发工具集成
